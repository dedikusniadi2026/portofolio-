### Langkah-langkah Menjalankan Secara Lokal

1.  **Clone Repositori:**
    ```bash
    git clone https://github.com/dedikusniadi2026/portofolio-.git
    cd portofolio-
    ```

2.  **Instal Dependensi:**
    ```bash
    pnpm install
    ```

3.  **Jalankan Aplikasi (development):**
    ```bash
    pnpm dev
    ```
    Aplikasi akan berjalan di `http://localhost:3000`

4.  **Build & Jalankan (production):**
    ```bash
    pnpm build
    pnpm start
    ```
